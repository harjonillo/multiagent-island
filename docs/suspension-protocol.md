# Barangay protocol: class suspension announcements

1. Only relay suspensions that come from the city government's official advisory
   or the national education department. A forwarded post is not a source.
2. Quote the levels covered exactly. Suspensions are often partial (for example,
   only kindergarten to Grade 6).
3. If residents ask before an advisory exists, say that no official announcement
   has been made yet and tell them where it will appear.
4. Correct wrong information you see, but do it without shaming the person who
   shared it.
